Financial Risk Analysis

Credit scoring model built to classify loan applicants into risk tiers (low / medium / high) using logistic regression with L2 regularisation. The full pipeline covers data wrangling, feature engineering, class imbalance treatment and model explainability with SHAP.

Business stakeholders receive clear explanations for each individual decision, enabling regulatory compliance and fair lending practices.

Key Highlights

  • 86% AUC-ROC on hold-out test set
  • SHAP beeswarm and waterfall plots for XAI
  • Threshold optimisation for business cost function
  • Automated model monitoring for data drift
