Marketing Analytics Dashboard

Interactive Power BI dashboard integrating data from multiple sources (ERP, CRM and e-commerce) to give sales managers a live view of performance across regions, product categories and time periods.

An automated SQL pipeline refreshes the data daily, ensuring decision-makers always work with up-to-date KPIs without manual exports.

Key Highlights

  • Real-time KPI cards: revenue, margin, units sold
  • Drill-through by region, product and salesperson
  • Automated daily ETL with Python + SQL
  • Row-level security for role-based access
