MatchSense AI

A complete semantic analysis system for matching resumes with job descriptions, powered by Artificial Intelligence and Natural Language Processing.

In this project, I developed both the NLP engine in Python and the interface prototype. The system uses Transformers (BERT model) to extract the true meaning behind candidates' experiences and skills, comparing them semantically — not just by keyword — against job requirements.

Key Highlights

  • Vector Search (FAISS) for fast and scalable matching.
  • Intelligent extraction of technical skills and soft skills from PDFs/DOCX.
  • Decoupled architecture: Python backend and modern React + Tailwind frontend.
