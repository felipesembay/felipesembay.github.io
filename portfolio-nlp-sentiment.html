NLP Sentiment Analysis

Fine-tuned BERT (bert-base-multilingual-cased) for 3-class sentiment classification (positive / neutral / negative) on Portuguese-language e-commerce reviews. The model was deployed as a Streamlit web app for real-time inference.

The project includes a complete NLP pipeline: text preprocessing, tokenisation, fine-tuning on domain-specific data, evaluation and a live demo interface.

Key Highlights

  • Multilingual BERT fine-tuned on 50k reviews
  • 89% accuracy, 88% weighted F1-score
  • Deployed Streamlit app for real-time demo
  • LIME explainability for model transparency
