Precificação Inteligente de Imóveis com Geolocalização

Projeto completo de precificação imobiliária que vai desde a análise exploratória dos dados até a implementação de um sistema de predição em produção, utilizando características estruturais do imóvel e features geoespaciais dinâmicas.

O modelo estima o valor de imóveis a partir do endereço (via Google Maps), calcula automaticamente scores de localização com base em POIs do OpenStreetMap (escolas, hospitais, mercados, parques, segurança, etc.) e retorna a previsão em tempo real por meio de uma API. Todo o pipeline foi desenvolvido com foco em escalabilidade, rastreabilidade e monitoramento do modelo.

Principais Destaques

  • Pipeline completo de Machine Learning em produção
  • Enriquecimento automático dos dados via Google Maps + OpenStreetMap
  • Cálculo dinâmico de scores geoespaciais em qualquer cidade do Brasil
  • Comparação entre preço anunciado vs. preço previsto, com métricas de erro
  • Monitoramento de data drift e performance do modelo
  • Separação clara entre camada de dados, modelo, API, frontend e observabilidade
  • Dashboard interativo com Metabase + Grafana
