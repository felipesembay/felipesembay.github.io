Precificação Inteligente de Imóveis com Geolocalização

Dois projetos end-to-end de Ciência de Dados e MLOps para precificação de imóveis, que compartilham a mesma base técnica: coleta → geocoding → enriquecimento geoespacial (POIs) → EDA e inferência estatística → modelagem → versionamento (MLflow) → API / interface → monitoramento.

O usuário digita um endereço, que é geocodificado (Google Maps / OpenCage); os scores de localização são calculados a partir de POIs do OpenStreetMap (escolas, hospitais, metrô, mercados, parques etc.) e o modelo retorna o preço estimado em tempo real pela API. O app está no ar na Vercel, com a API no Render e o banco no Azure.

🏙️ Aluguel Mensal — São Paulo (SP)

Previsão do aluguel de ~30 mil anúncios residenciais em São Paulo. Antes do modelo, um estudo completo de inferência estatística (OLS com efeito fixo de região e erros agrupados) para separar associação de efeito controlado. XGBoost otimizado com Optuna, 20 features numéricas + tipo do imóvel.

  • Central não é o mesmo que nobre: o aluguel por m² tem pico a ~4 km do marco zero, no eixo Pinheiros–Vila Mariana–Itaim (variação de 5,2× entre regiões)
  • Elasticidade da área menor que 1: +10% de área → +6,3% de aluguel
  • Associação ≠ efeito: mobiliado parece +42% e piscina +41%; controlando tamanho e região, ficam em +14% e +8%
  • Metrô é a exceção entre os POIs: +19% a até 300 m da estação, caindo para +5% a 1,5–2 km
  • Condomínio + IPTU somam, na mediana, 23,6% sobre o aluguel

Principais Destaques

  • Pipeline completo de ML em produção (frontend React na Vercel + FastAPI no Render + PostgreSQL no Azure)
  • Enriquecimento automático dos dados via geocoding + OpenStreetMap
  • Versionamento de modelos e promoção champion × challenger com o MLflow Model Registry
  • Monitoramento de data drift (Wasserstein) e desempenho real com Evidently, alertas no Prometheus e Grafana
  • Retreino automático do modelo de aluguel com Airflow (gatilhos de desempenho, drift e idade)
  • Infraestrutura em nuvem como código com Terraform, dentro do plano gratuito
