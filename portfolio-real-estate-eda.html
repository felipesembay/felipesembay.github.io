Intelligent Real Estate Pricing with Geolocation

Complete real estate pricing project spanning from exploratory data analysis to the implementation of a prediction system in production, utilizing structural property characteristics and dynamic geospatial features.

The model estimates property values based on the address (via Google Maps), automatically calculates location scores based on OpenStreetMap POIs (schools, hospitals, markets, parks, security, etc.), and returns real-time predictions through an API. The entire pipeline was developed focusing on scalability, traceability, and model monitoring.

Key Highlights

  • Complete Machine Learning pipeline in production
  • Automatic data enrichment via Google Maps + OpenStreetMap
  • Dynamic calculation of geospatial scores in any city in Brazil
  • Comparison between advertised price vs. predicted price, with error metrics
  • Monitoring of data drift and model performance
  • Clear separation between data layer, model, API, frontend, and observability
  • Interactive dashboard with Metabase + Grafana
