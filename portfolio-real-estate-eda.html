Intelligent Real Estate Pricing with Geolocation

Two end-to-end Data Science and MLOps projects for real-estate pricing that share the same technical foundation: data collection → geocoding → geospatial enrichment (POIs) → EDA and statistical inference → modeling → versioning (MLflow) → API / interface → monitoring.

The user types an address, which is geocoded (Google Maps / OpenCage); location scores are calculated from OpenStreetMap POIs (schools, hospitals, subway, markets, parks, etc.) and the model returns the estimated price in real time through the API. The web app is live on Vercel, with the API hosted on Render and the database on Azure.

🏙️ Monthly Rent — São Paulo (SP)

Rent prediction for ~30k residential listings in São Paulo. Before modeling, a complete statistical inference study (OLS with region fixed effects and clustered errors) to separate association from controlled effect. XGBoost tuned with Optuna, 20 numerical features + property type.

  • Central is not the same as upscale: rent per m² peaks ~4 km from downtown, on the Pinheiros–Vila Mariana–Itaim axis (5.2× variation between regions)
  • Area elasticity below 1: +10% area → +6.3% rent
  • Association ≠ effect: furnished looks like +42% and pool +41%; controlling for size and region, they drop to +14% and +8%
  • Subway is the exception among POIs: +19% within 300 m of a station, decaying to +5% at 1.5–2 km
  • Condo fee + property tax add a median of 23.6% on top of rent

Key Highlights

  • Complete ML pipeline in production (React frontend on Vercel + FastAPI on Render + PostgreSQL on Azure)
  • Automatic data enrichment via geocoding + OpenStreetMap
  • Model versioning and champion × challenger promotion with the MLflow Model Registry
  • Data drift (Wasserstein) and real performance monitoring with Evidently, Prometheus and Grafana alerts
  • Automatic rent model retraining with Airflow (performance, drift and age triggers)
  • Cloud infrastructure as code with Terraform, kept within the free tier
