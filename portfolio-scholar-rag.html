ScholarRAG: RAG Assistant for Academic Research and Writing

Retrieval-Augmented Generation assistant built during my master's degree. You feed a project with your own material (papers, books, class notes, code, datasets) and your own results, and the application answers questions, drafts the article section by section, reviews it and proposes corrections, always with citations tied to the sources you provided.

Central design rule: the language model never writes a reference. It only points to numbered sources ([1], [2, 3]); author, year, page and the reference list are produced by code from the project library (ABNT NBR 10520/6023 or APA 7). Markers pointing to non-existent sources are dropped, so an invented reference cannot reach the final text.

Architecture

React (Vite) → FastAPI → ingestion (pdfplumber / Tesseract / Docling, Office, notebooks) → Elasticsearch 8.19 with hybrid BM25 + kNN search and RRF fusion (bge-m3 embeddings) → cross-encoder reranking (bge-reranker-v2-m3) → any OpenAI-compatible LLM (OpenRouter, OpenAI or Ollama), with separate models for chat, writing and review.

Features

  • Ingestion of PDF, DOCX, PPTX, XLSX/CSV, Markdown, Jupyter notebooks, R/Python scripts, images (OCR) and nested ZIP files; tables preserved and DOIs enriched via Crossref
  • Editable bibliographic library separating citable literature, supporting material and research results; BibTeX export
  • Chat with clickable citations that open the exact excerpt and page of the source
  • Section-by-section article drafting, import of Word/PDF/Markdown drafts and export to Markdown, DOCX and LaTeX (abnTeX2 or natbib, ready for Overleaf)
  • Review combining exact checks and a reviewer model that receives the cited excerpts, flagging citations that do not support the claim
  • Per-section correction proposals with paragraph/word diff, accepted or rejected by the author

Key Highlights

  • Hallucinated references blocked by design: citations are formatted by code, never by the LLM
  • Hybrid retrieval + reranking with embedding and reranker models running locally
  • Provider-agnostic LLM layer (free or paid models, cloud or local with Ollama)
  • Full stack in a single docker-compose up (Elasticsearch, FastAPI and React)
